# Triage note: INC-1101

## Summary
funding-svc is rejecting loan disbursements at 34% against a 1% baseline. The alert is SEV2 and has been firing for about 15 minutes, with 38 disbursements pending. The rejections began right after funding-svc 4.18.0 rolled out at 09:41 UTC. Before the rollout, disbursements were accepted.

## Likely cause
Release 4.18.0 changed how bank account numbers are normalized before the ACH (bank transfer) request is built. The processor's pre-validation now rejects some of those requests with return code R04, "invalid account number structure." The new normalizer is probably malforming some account numbers. Not all of them fail, because LN-SYN-0924 was accepted after the rollout. I haven't confirmed this: the processor's status page has not been checked, which runbook step 3 asks for.
